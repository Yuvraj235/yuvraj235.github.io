What if every field had a team of AI agents working beside it?

That question is why I do this work.

I believe AI should work beside people everywhere: in hospitals, courts, factories and businesses. It should take on the routine work and hand the hard calls to a human, with the evidence laid out.

Agents that do the work

Chatbots answer questions. Agents read the record, run the checks, call the right tools and finish the task. That shift from talking to doing is what excites me most about AI right now.

AI you can question

Whether it's a diagnosis or a legal answer, trust is everything. An agent should explain why it decided something, say when it isn't sure, and never act beyond the permissions it was given.

Always on the next thing

AI changes every month, and that's what I love about it. I read the new papers, try new models and tools the week they land, and turn the useful ones into working systems.

What I know about AI

The ideas I work with every day, what they actually do, and how I've used them.

Agentic AI

An agent breaks a goal into steps, picks a tool for each one, remembers what happened and checks its own output. I design multi-agent systems where each agent has one job and a clean handoff, like the 8+ parallel agents in my hospital simulation.

LangChain, OpenAI API, n8n, Make, MCP

LLMs and RAG

Language models write fluently but can invent facts. Retrieval-augmented generation fixes that by finding the right passages with embeddings and vector search, then making the model answer from them.

FAISS, Pinecone, ChromaDB, Ollama, Llama 3.3 on Groq

Computer vision

CNNs like ResNet and EfficientNet learn visual features layer by layer. Detectors like YOLO find and box every object in one pass, fast enough for a live production line.

PyTorch, OpenCV, YOLOv5, YOLOv7

Multimodal AI

Real decisions use more than one kind of data. I give images, text and tables each their own specialist model, then fuse their outputs into one prediction.

ResNet50, EfficientNet-B4, BioBERT

Medical AI

Medical data arrives as DICOM scans, FHIR records and free-text notes, and all of it is private. I build HIPAA-aware pipelines with a clinician kept in the loop.

DICOM, FHIR, clinical NLP, NER, X-ray and CT

Explainable AI

A model people can't question won't get used. SHAP shows which features pushed each prediction; adding it cut clinicians' AI-review time by about 25% at OHSL.

SHAP, XGBoost

Machine learning on tables

For tabular data, gradient-boosted trees often beat deep learning. Picking the right metric matters too: in cancer screening, missing a case costs more than a false alarm, so sensitivity counts.

scikit-learn, XGBoost, A/B testing

MLOps

A model only helps once it runs reliably. I package models in Docker, serve them through FastAPI or gRPC, track experiments in MLflow and schedule pipelines with Airflow.

Kubernetes, CI/CD, AWS, GCP, Azure

Generative voice

Text-to-speech models now carry emotion and regional accents. I've used them to give a brand a natural Arabic voice in the Syrian dialect for automated social content.

ElevenLabs, automation workflows

How I build an agent, in any field

The same five steps, whether the agent screens a scan, answers a legal question or posts for a brand.

  1. Start from the cost of a mistake

    Before picking a model, I write down what a wrong answer costs. A missed tumour needs far more checking than a late social post.

  2. Ground it in the real record

    Agents read from the source of truth, such as patient records, the text of the law or a client's database, so every answer traces back to something real.

  3. Give it the fewest tools that work

    One agent holding database write, shell and network access at once is a security risk. I split permissions across narrow tools, each with only what it needs.

  4. Check before it acts

    A second model or a person reviews anything that matters, and the agent says so when it can't verify a result.

  5. Test on data it hasn't seen, then ship

    Measure on held-out cases, deploy behind an API, watch real usage and tune.
